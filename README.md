# СВОИ ТАКСИ — сборщик адресов (отдельный Android APK)

Это **только клиентское приложение** для полевого сбора координат домов. Исходники опубликованы отдельно, чтобы сборка Android APK выполнялась на бесплатных GitHub-hosted runners и не отнимала память у действующего сервера такси.

## Что есть в версии 0.7

- GPS и ручной выбор точки на карте без обязательного GPS
- Сохранение адреса сразу под картой; ошибки отображаются рядом с кнопкой
- Зелёные маркеры с номерами домов, включая адреса других участников
- Индивидуальные ключи сборщиков, общая синхронизация с `https://svoi-taxi24.ru/api/collector-addresses`
- Работа офлайн, экспорт/импорт локальных адресов GeoJSON

**В репозитории нет и не должно быть** ключей сборщиков, паролей VPS, базы домов, заказов, данных клиентов и исходников сервера. В APK не вшит рабочий секрет: участник вводит личный ключ после установки. Не добавляйте реальные адреса/координаты в issues, коммиты или тесты.

## Безопасная установка

Это предварительная сборка `ru.svoitaxi.addresscollector.preview`, которая **устанавливается рядом** со старым `ru.svoitaxi.addresscollector`. Мы специально используем другой package ID, потому что подпись прежней debug-сборки на другом runner может не совпасть. **Не удаляйте старое приложение** и предварительно выгрузите локальные адреса в GeoJSON и проверьте их синхронизацию. Вход в общую карту выполняется с личным ключом участника.

Debug APK из разных GitHub-hosted сборок тоже может иметь разную подпись. Для постоянных обновлений без переустановки потребуется стабильная приватная подпись приложения, хранящаяся отдельно от публичного кода.

## Как собрать на GitHub

В публичном репозитории откройте **Actions → Build SVOI address collector 0.7 APK → Run workflow** (или дождитесь запуска на `main`). После зелёного результата скачайте архив в разделе **Artifacts**, распакуйте `address-collector-debug.apk` и установите на Android.

GitHub-hosted runners собирают APK отдельно от VPS. Здесь нет серверных релизов: workflow не подключается к SSH, Docker production, базе данных и не меняет сайт такси.

## Локальная сборка

Требуются Java 17, Android SDK 36, Gradle 9.5 и Node 22:

```sh
npm install --ignore-scripts --no-audit --no-fund
node --test tests/address-collector-owner.test.mjs tests/address-collector-map-save-ui.test.mjs
cd android-driver
gradle :address-collector:assembleDebug
```

Исходный код опубликован для отдельной сборки APK. Публикация на GitHub сама по себе не предоставляет сторонним лицам лицензию на коммерческое использование исходников.

## Безопасность и дальнейшая разработка

- Не переносите Git-историю основного закрытого репозитория в этот публичный проект.
- Не добавляйте `.env`, токены, `*.jks`, реальные выгрузки GeoJSON/CSV и любые учетные данные.
- Серверную часть адресной базы и основной проект такси оставляем в приватном репозитории.
